# Signatures read from titles' own library code, for the XDK 4831 functions XbSymbolDatabase
# (signatures.txt) has no usable signature for. Same format as signatures.txt; the runtime and
# `anybox` read this file after it, as one list. Patterns come from the code of BLiNX The Time
# Sweeper and Dragon's Lair 3D; link-dependent bytes are `??`.
#
# Most IDirectSound and IDirectSoundBuffer methods are thunks of one shape: step `this` back (by 8,
# or 0x1C for a buffer), call the C++ method, return. Those are told apart by what they call
# (`| offset: pattern`): the method, which enters DirectSound's critical section and calls the voice
# or buffer function under it, and that function, whose code is its own (SetHeadroom stores at
# +0x20 and moves the volume at +0x1C, GetStatus reads the voice state at +0x12, and so on).
# SetMixBins and SetMixBinVolumes go one call deeper, to the settings function each calls. Match
# numbers would not do: BLiNX's third two-argument thunk is SetHeadroom, its fourth SetMixBins,
# its fifth SetMixBinVolumes and its third three-argument one SetBufferData, which in Dragon's Lair
# are GetStatus, SetFormat, SetFrequency and SetPlayRegion.
#
# SetFrequency is here rather than in signatures.txt: XbSymbolDatabase's matches several thunks in
# both titles.
